# Thanh tìm kiếm — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Thêm thanh tìm kiếm vào thanh điều hướng và một trang kết quả, tìm được nội dung tiếng Việt kể cả khi gõ không dấu.

**Architecture:** Toàn bộ truy vấn gói trong `models/search.js` (một hàm `timKiem`), route công khai `GET /tim-kiem` render `views/public/search.ejs` dùng lại kiểu thẻ bài của trang chủ. Tìm không dấu nhờ collation `utf8mb4_0900_ai_ci` ngay trong mệnh đề `WHERE` — không thêm cột, không thêm bảng, không thêm dịch vụ.

**Tech Stack:** Node.js 24 · Express 4 · EJS · MySQL 8.4 (`mysql2`) · test bằng `node:test` + `supertest`

**Spec:** `docs/superpowers/specs/2026-08-30-tim-kiem-design.md`

## Global Constraints

- Không thêm thư viện mới. Không sửa `schema.sql`, `models/posts.js`, `models/categories.js`, hay bất kỳ file nào trong `routes/admin.js` / `views/admin/`.
- **64 test hiện có phải vẫn xanh** sau mỗi task.
- Collation tìm kiếm: `utf8mb4_0900_ai_ci`, viết hoa/thường như vậy, dùng cho **cả 5 trường** và cho cả biểu thức `ORDER BY`.
- Chuỗi collation được nối thẳng vào câu SQL (nó là hằng số trong code, **không bao giờ** lấy từ người dùng). Mọi giá trị do người dùng nhập vẫn đi qua tham số `?`.
- Thứ tự bắt buộc khi dựng mẫu LIKE: **vô hiệu hóa `\` `%` `_` trước**, rồi mới bọc `%…%`. Làm ngược là hỏng.
- Từ khóa cắt tối đa **100 ký tự**. Kết quả **10 bài/trang**. Chủ đề khớp tối đa **8**.
- Bài `draft` không bao giờ xuất hiện trong kết quả, kể cả khi đã đăng nhập quản trị.
- Chữ hiển thị cho người dùng viết bằng tiếng Việt có dấu.
- Mọi giá trị hiển thị dùng `<%= %>` (tự escape). Không dùng `<%- %>` cho bất kỳ dữ liệu nào đến từ người dùng.
- Chạy test bằng `npm test` (đã cấu hình `--test-concurrency=1`). MySQL bật bằng `docker start loichua-mysql`.
- **Về git:** thư mục vẫn chưa phải kho git. Bỏ qua mọi bước Commit cho tới khi người dùng đồng ý khởi tạo.

const { pool } = require('../db');

// Hằng số trong code, không bao giờ lấy từ người dùng — nên nối thẳng vào SQL được.
const AI = 'utf8mb4_0900_ai_ci';
const MAX_LENGTH = 100;
const MAX_CHU_DE = 8;

function escapeLike(s) {
  return String(s).replace(/[\\%_]/g, (c) => '\\' + c);
}

function chuanHoa(q) {
  const t = String(q == null ? '' : q).trim();
  if (!t) return null;
  return t.slice(0, MAX_LENGTH);
}

Chèn trước dòng `module.exports`:

```js
const CHON = `
  SELECT p.*, c.name AS category_name, c.slug AS category_slug
  FROM posts p
  LEFT JOIN categories c ON c.id = p.category_id
`;

const DIEU_KIEN = `
  p.status = 'published' AND (
       p.title      COLLATE ${AI} LIKE ?
    OR p.body       COLLATE ${AI} LIKE ?
    OR p.verse_ref  COLLATE ${AI} LIKE ?
    OR p.verse_text COLLATE ${AI} LIKE ?
    OR c.name       COLLATE ${AI} LIKE ?
  )
`;

async function timKiem({ tuKhoa, page = 1, perPage = 10 }) {
  // Vô hiệu hóa ký tự đại diện TRƯỚC, rồi mới bọc %…% — làm ngược là hỏng.
  const mau = `%${escapeLike(tuKhoa)}%`;
  const nam = [mau, mau, mau, mau, mau];
  const offset = (Math.max(1, Number(page)) - 1) * perPage;

  const [countRows] = await pool.query(
    `SELECT COUNT(*) AS n
     FROM posts p LEFT JOIN categories c ON c.id = p.category_id
     WHERE ${DIEU_KIEN}`,
    nam
  );

  const [rows] = await pool.query(
    `${CHON}
     WHERE ${DIEU_KIEN}
     ORDER BY (p.title COLLATE ${AI} LIKE ?) DESC, p.created_at DESC, p.id DESC
     LIMIT ? OFFSET ?`,
    [...nam, mau, perPage, offset]
  );

  const [chuDeKhop] = await pool.query(
    `SELECT id, name, slug FROM categories
     WHERE name COLLATE ${AI} LIKE ?
     ORDER BY name ASC LIMIT ?`,
    [mau, MAX_CHU_DE]
  );

  return { rows, total: Number(countRows[0].n), chuDeKhop };
}
```

    const { rows, total, chuDeKhop } = await timKiem({ tuKhoa, page, perPage: PER_PAGE });

      total,
      chuDeKhop,
      page,
      totalPages: Math.max(1, Math.ceil(total / PER_PAGE)),
    });
  } catch (err) { next(err); }
});
